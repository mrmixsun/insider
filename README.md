# Инсайдер

> **Диалоговый агент для организации структурированных интервью с экспертами и упаковки их в контент по фреймворку STARRI. Работает как скилл в AI-клиенте и как Telegram-бот.**

## Проблема

В любой компании есть люди с глубокой экспертизой — техлиды, аналитики, продакты, руководители. У них в голове десятки сильных историй: как решали сложную задачу, как выкатили продукт за 2 месяца, как подтвердили гипотезу через исследование.

Проблема: **эти истории остаются в головах**. Потому что:

- Интервью — это «просто поговорить», без структуры
- Писать контент за эксперта — долго, эксперту некогда
- Никто не знает, какую историю куда применить (доклад? пост? кейс?)
- Результат: контент-план пустой, а экспертиза есть

**Инсайдер решает это:** проводит структурированное интервью (STARRI), маппит историю на аудитории и форматы, и генерирует черновик контента.

## Для кого

| Кто | Зачем |
|-----|-------|
| **PR / Communications Manager** | Вытаскивать истории из коллег для контент-плана |
| **Content Manager** | Быстро получать структурированные черновики для постов, докладов, кейсов |
| **Team Lead / Эксперт** | Превращать свой опыт в контент, не тратя время на написание |
| **HR / Internal Comms** | Собирать кейсы для внутренних и внешних коммуникаций |
| **CEO / Product Manager** | Упаковывать стратегические результаты для рынка |

## Pipeline работы

```
/init         /extract         /map          /generate
──────→ ──────────→ ──────────→ ──────────→

Настройка    Интервью с       Выбор        Генерация
контекста    экспертом        аудитории    черновика
компании     по STARRI        и формата    контента
(1 раз)      (15-20 мин)
```

1. **`/init`** — один раз настраиваете контекст компании (кто вы, домены, аудитории, форматы). Остальное скилл знает сам.
2. **`/extract`** — садитесь с коллегой на 15-20 минут, скилл проводит интервью. На выходе — структурированная STARRI-история.
3. **`/map`** — скилл предлагает, для какой аудитории и в каком формате эта история «выстрелит». Вы подтверждаете.
4. **`/generate`** — скилл пишет черновик контента. Вы правите, публикуете.

## Что получаете на выходе

- **Telegram-пост** — 300-500 слов, готовый к публикации
- **Заявку на доклад** — для конференции с тезисами и outcome
- **Кейс** — полноценный разбор с проблемой, решением, метриками и уроками

## Когда НЕ использовать

- ❌ Для автоматического контент-маркетинга без человеческого интервью
- ❌ Для генерации контента «из воздуха» — **Инсайт всегда от эксперта, не от AI**
- ❌ Когда эксперту нужно просто «рассказать, а вы запишете» — используйте диктофон, тут глубже

## Быстрый старт

```bash
# 1. Клонируй репозиторий
git clone https://github.com/mrmixsun/insider.git
# 2. Открой в любом AI-клиенте:
#    Claude Code → cd insider && claude
#    VS Code + Claude → File → Open → insider
#    Cursor → File → Open → insider
#    AI Sreda → File → Open → insider
#    ChatGPT → загрузи проект как knowledge (experimental)
# 3. Вызови /init — настроишь контекст за 2 минуты
# 4. Вызови /extract — интервью с первым экспертом
```

Никаких внешних API, ключей, подписок, docker-образов. Всё работает внутри AI-клиента — достаточно прочитать SKILL.md.

## Архитектура

Инсайдер оперирует 4 слоями данных:

```
Layer 0: Business DNA     → кто вы, домены, продукты, стратегия
Layer 1: Expert Profile   → кто эксперт, его роль и фокус
Layer 2: STARRI Story     → контекст → задача → действие → результат → relevance → инсайт
Layer 3: Content Map      → аудитории, форматы, правила маппинга
```

**Ключевой принцип:** AI не генерирует факты. Результаты, метрики и инсайт — только от эксперта. AI структурирует и упаковывает.

## Структура проекта

```
the-insider/
├── .claude/skills/the-insider/
│   ├── SKILL.md              — Точка входа скилла (все команды)
│   ├── config/protocol.md    — Протокол STARRI-интервью
│   └── references/           — Шаблоны артефактов
├── business/
│   ├── dna.yaml              — Business DNA (Layer 0)
│   └── content_map.yaml      — Content Map (Layer 3)
├── experts/profiles/         — Профили экспертов (не коммитятся)
├── stories/my_data/          — STARRI-истории (не коммитятся)
├── artifacts/my_data/        — Сгенерированные черновики (не коммитятся)
├── CLAUDE.md
└── README.md
```

Фреймворк: [STARRI](https://github.com/mrmixsun/insider) — адаптация [STARR от katilevina](https://github.com/katilevina/starry) с добавлением Relevance и Insight для контент-задач.

## Telegram Bot

Инсайдер доступен как Telegram-бот — развёрнут на Railway, база данных на Supabase.

**Ссылка:** https://t.me/the_insider_bot

Попробовать можно сразу, без клонирования репозитория. Команды те же: `/init` → `/extract` → `/map` → `/generate`.

Под капотом:
- **Python + python-telegram-bot v20** — асинхронный фреймворк
- **asyncpg + Supabase Pooler** — PostgreSQL, IPv4-совместимый коннект
- **polza.ai (DeepSeek V4 Flash)** — AI-провайдер
- **Railway** — деплой

```
service/
├── bot/
│   ├── main.py          — точка входа, диспатчер
│   ├── handlers.py      — все Telegram-хендлеры
│   ├── ai/
│   │   └── client.py    — AI-клиент + state machine
│   └── db.py            — asyncpg прослойка
├── db/
│   └── schema.sql       — идемпотентная миграция
├── Dockerfile
├── requirements.txt
└── railway.json
```
