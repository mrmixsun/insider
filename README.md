# The Insider

**Диалоговый агент для вытягивания экспертизы и упаковки в контент.**

The Insider проводит структурированное интервью с внутренним экспертом (техлидом, аналитиком, продактом), извлекает его знания в формат STARRI, маппит на бизнес-контекст и аудитории, и генерирует готовые контент-артефакты.

## Быстрый старт (для демо)

```bash
# 1. Установи AI Sreda (если ещё нет)
# 2. Открой проект в AI Sreda:
#    File → Open → ~/Projects/the-insider
# 3. Настрой контекст (один раз):
#    Вызови /init и ответь на вопросы о компании
#    (Если конфигурация уже есть — /init покажет и подтвердит)
# 4. Проведи интервью с экспертом:
#    Вызови /extract
# 5. Смапь историю на контент:
#    Вызови /map {story_id}
# 6. Сгенерируй черновик:
#    Вызови /generate {story_id} --audience ... --format ...
```

## Архитектура

```
The Insider обрабатывает 4 слоя данных:

Layer 0: Business DNA (business/dna.yaml)
  → Описание компании, домены, продукты, стратегия
  → Настраивается 1 раз через /setup

Layer 1: Expert Profile (experts/profiles/)
  → Кто эксперт, его роль, домен, текущий фокус
  → Создаётся при первом /extract

Layer 2: Story Data (stories/my_data/)
  → История в формате STARRI (Situation, Task, Action, Result, Relevance, Insight)
  → Формируется в диалоге через /extract

Layer 3: Content Map (business/content_map.yaml)
  → Аудитории (B2G/B2B/B2C), форматы (пост/доклад/кейс), правила маппинга
  → Настраивается через /setup
```

## Команды

| Команда | Функция |
|---------|---------|
| `/init` | Первичная настройка контекста (Business DNA + Content Map) |
| `/setup` | Переконфигурация (то же, что `/init`, без приветствия) |
| `/extract` | Провести STARRI-интервью с экспертом |
| `/map` | Смаппить историю на аудиторию и формат |
| `/generate` | Сгенерировать черновик контента |

## Формат STARRI

```
S — Situation   → Контекст, стейкхолдеры, stakes
T — Task        → Цель, метрика успеха, ограничения
A — Action      → Что делали, личный вклад, инструменты
R — Result      → Было N → стало M, impact
R — Relevance   → Для кого это важно, почему (проверяется с экспертом)
I — Insight     → Самое неочевидное (только от эксперта, не AI)
```

## Форматы вывода

- **Telegram-пост** — 300-500 слов, hook, CTA, хэштеги
- **Заявка на доклад** — тема, тезисы, для кого, outcome
- **Кейс** — проблема, решение, результат, уроки

## Git-политика

- **Не коммитится**: `my_data/` (пользовательские данные), большие файлы
- **Коммитится**: SKILL.md, шаблоны, конфиги, README, CLAUDE.md
- При старте проекта: `git init && git add . && git commit -m "init: scaffold"`
